# Mục tiêu

| Mục tiêu                                       | Đo bằng                                          |
| ---------------------------------------------- | ------------------------------------------------ |
| Mọi công việc của phòng ban nằm trên Dashboard | % phòng ban có Dashboard đang dùng               |
| Trách nhiệm rõ ràng                            | 100% task có đúng 1 người phụ trách chính        |
| Giảm trễ hạn                                   | Tỉ lệ task quá hạn theo tháng                    |
| Lãnh đạo nắm tình hình nhanh                   | Executive Overview tải < 2 giây                  |
| Số hoá quy trình HR                            | Đơn nghỉ phép/phê duyệt xử lý 100% trên hệ thống |
| Bảo mật dữ liệu nhân sự                        | Mọi thay đổi lương/quyền có audit log            |

## Ngoài phạm vi (hiện tại)

- CRM khách hàng (lead, deal, hợp đồng bán hàng) — "CRM" chỉ là tên dự án.
- Nhiều công ty trên một hệ thống (multi-tenant).
- Ứng dụng mobile native, đa ngôn ngữ.
