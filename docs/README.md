# Tài liệu

| Thư mục                                    | Nội dung                                      | Trạng thái                         |
| ------------------------------------------ | --------------------------------------------- | ---------------------------------- |
| `product/`                                 | Tầm nhìn, mục tiêu, vai trò, thuật ngữ        | ✅                                 |
| `requirements/`                            | Quy tắc nghiệp vụ (BR-xx)                     | ✅ business-rules · ⏳ còn lại     |
| `architecture/`                            | Hệ thống, FE, BE, auth, phân quyền, deploy    | ✅ · ⏳ database, realtime         |
| `decisions/`                               | ADR 001–006                                   | ✅                                 |
| `api/`                                     | Tổng quan, xác thực, lỗi, phân trang          | ✅ · endpoints viết khi làm module |
| `features/work-management/`                | Workspace, Dashboard, Task, kéo thả, activity | ✅                                 |
| `features/<hrm>/`                          | Đặc tả HRM                                    | ⏳ viết khi tới module             |
| `ui-ux/`                                   | Màu                                           | ✅ colors · ⏳ còn lại             |
| `database/`                                | Schema, RLS, migration                        | ⏳ viết cùng nhiệm vụ schema       |
| `deployment/`, `development/`, `security/` |                                               | ✅ getting-started · ⏳ còn lại    |

Quy tắc: tài liệu đi cùng code — làm module nào cập nhật docs module đó.
